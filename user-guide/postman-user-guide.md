## Introduction

Postman is an API platform developed by Postman Inc. This guide helps users navigate the Postman interface, including Collections, Environments, Requests, and API testing features on Windows.

## How to Use This Guide

Read this guide from top to bottom if you are a beginner. If you are looking for a specific feature, use **Ctrl+F** to search by keyword.

## Prerequisites

Before you begin, ensure the following requirements are met:

- [ ] A stable internet connection  
- [ ] Free Postman account created  
- [ ] Postman is installed on your device  
Download: https://www.postman.com/downloads/

## Getting Started

### Step 1: Launch Postman App

Double-click the **Postman icon** on your desktop or search for it in the **Start menu** and click **Open**.

### Step 2: Explore the Welcome Screen

Go through the sign-up process, UI elements, icons, and instructions shown when you first open the app.

### Step 3: Understand the Interface

There are 5 main elements on the left sidebar:

- **Collections:** Store and organize API requests and share them with others.  
- **Environments:** Manage variables for different contexts.  
- **Spec Hub:** Design APIs using OpenAPI 3.0 or AsyncAPI 2.0.  
- **Flows:** Create visual workflows for APIs.  
- **Mock servers:** Simulate APIs for testing without a real backend.  

> 💡 **Tip:** You can sign in using Google or GitHub for faster access.  
> ⚠️ **Warning:** Read Terms and Privacy Policy before proceeding.

## Common Tasks

### Task 1: Account Creation

**Steps:**

1. Enter your email → click **Create Free Account**  
2. Set name and password → click **Create Free Account**  
3. Verify email using the code sent  
4. Click **Allow access** in Windows security alert  
5. Enter name and role → type a request  
6. Click **Get started with AI**

> 💡 **Tip:** You can start with “Send a GET request”.

**Expected Result:** Account created successfully.

---

### Task 2: Create a New Request

**Steps:**

1. Click **Create New (Ctrl+N)** or **‘+’ icon**  
2. Click **Save**  
3. Enter title and choose collection  
4. Click **Save**

**Expected Result:** Request created successfully.

---

### Task 3: Change the Color Theme

**Steps:**

1. Go to **Settings → App settings**  
2. Select **Themes**  
3. Choose daytime theme  
4. Choose nighttime theme  

> 💡 **Tip:** Dark mode is better for long sessions.

**Expected Result:** Theme updated successfully.

---

### Task 4: Change Font Size

**Steps:**

1. Open **Settings → App settings**  
2. Go to **General → Editor settings**  
3. Adjust **Font size (px)**  

> 💡 **Tip:** Choose a comfortable reading size.

**Expected Result:** Font size updated successfully.

---

### Task 5: Rename Workspace

**Steps:**

1. Go to **Settings → Workspace settings**  
2. Click workspace name  
3. Enter new name and save  

**Expected Result:** Workspace renamed successfully.

---

### Task 6: Delete a Workspace

**Steps:**

1. Open **Settings → Workspace settings**  
2. Scroll down → click **Delete workspace**  
3. Type **Delete** → confirm  

> ⚠️ **Warning:** This action cannot be undone.

**Expected Result:** Workspace deleted successfully.

## Troubleshooting

### Issue 1: Account creation failed

**Cause:**
- Unstable internet  
- Invalid credentials  
- Wrong verification code  

**Fix:**

1. Use stable internet  
2. Verify email and password  
3. Enter correct verification code  
4. Retry  

---

### Issue 2: App closes automatically

**Cause:**
- Outdated version  
- Corrupt installation  

**Fix:**

1. Update app (**Menu → Help → Check for Updates**)  
2. Reinstall latest version  

---

### Issue 3: Unable to send request

**Cause:**
- Internet issues  
- Incorrect API URL  
- Wrong request method  

**Fix:**

1. Check internet connection  
2. Verify API URL  
3. Select correct method  
4. Retry

## FAQ

**Q1: What is Postman?**  
**A:** A platform for designing, testing, and managing APIs collaboratively.

**Q2: Is Postman available on mobile?**  
**A:** No official app; web version can be used.

**Q3: Can deleted workspace be recovered?**  
**A:** No, deletion is permanent.

**Q4: How to access integrations?**  
**A:** Home → Integration → Browse → Add Integration

**Q5: How to clear cache?**  
**A:** Menu → Help → Clear cache and reload
