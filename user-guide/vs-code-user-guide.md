## Introduction

Visual Studio Code (VS Code) is a code editor developed by Microsoft. This guide helps users navigate the VS Code interface, including the Explorer, Extensions, Terminal, and Debug features on Windows.

## How to Use This Guide

Read this guide from top to bottom if you are a beginner. If you are looking for a specific feature, use **Ctrl+F** to search by keyword.

## Prerequisites

Before you begin, ensure the following requirements are met:

- [ ] A stable internet connection  
- [ ] VS Code is installed on your device  
Download: https://code.visualstudio.com/download

## Getting Started

### Step 1: Launch the VS Code App

Double-click the VS Code icon on your desktop or search "Visual Studio Code" in the Start menu.

### Step 2: Explore the Welcome Screen

Go through the basic customization options and tutorials available on the Welcome tab.

### Step 3: Understand the Interface

There are 6 main icons on the left sidebar:

- **Explorer** – Browse, open, and manage project files and folders  
- **Search** – Find and replace text across files  
- **Source Control** – Track changes using Git  
- **Run and Debug** – Run and debug code  
- **Remote Explorer** – Connect to remote environments  
- **Extensions** – Install additional tools  

> 💡 **Tip:** Dark theme is easier on the eyes during long sessions.  
> ⚠️ **Warning:** Only open trusted files and folders.

## Common Tasks

### Task 1: Creating a New File

**Steps:**

1. Click **File** in the menu bar  
2. Click **New Text File (Ctrl+N)**  
3. Click **File → Save As (Ctrl+Shift+S)**  
4. Choose location and enter file name  
5. Click **Save**

**Expected Result:** A new file is created.

---

### Task 2: Changing the Color Theme

**Steps:**

1. Click **Settings icon** (bottom left)  
2. Go to **Themes → Color Theme (Ctrl+K Ctrl+T)**  
3. Select a theme  

**Expected Result:** Theme changes immediately.

---

### Task 3: Changing Font Size

**Steps:**

1. Open **Settings (Ctrl+,)**  
2. Go to **Text Editor → Font**  
3. Adjust **Font Size**  

**Expected Result:** Font size updates instantly.

---

### Task 4: Enabling Auto Save

**Steps:**

1. Click **File**  
2. Click **Auto Save**

**Expected Result:** Files are saved automatically.

---

### Task 5: Installing an Extension

**Steps:**

1. Click **Extensions (Ctrl+Shift+X)**  
2. Search for an extension  
3. Click **Install**

**Expected Result:** Extension is installed successfully.

---

### Task 6: Opening the Terminal

**Steps:**

1. Click **Terminal** menu  
2. Select **New Terminal (Ctrl+Shift+`)**

**Expected Result:** Terminal opens successfully.

## Troubleshooting

### Issue 1: Installation fails

**Cause:**
- Low storage  
- Corrupt installer  
- System not compatible  

**Fix:**

1. Free up storage  
2. Verify system requirements  
3. Download latest installer  
4. Retry installation  
5. Use ZIP version if needed  

---

### Issue 2: Extensions not installing

**Cause:**
- Internet issues  
- Permissions blocked  
- Outdated VS Code  
- Low storage  

**Fix:**

1. Check internet  
2. Enable extension permissions  
3. Update VS Code  
4. Free up space  
5. Retry  

---

### Issue 3: Terminal not opening

**Cause:**
- No folder/workspace open  
- Extension conflict  
- Corrupt settings  

**Fix:**

1. Open a folder/workspace  
2. Disable problematic extensions  
3. Reset settings (**Ctrl+Shift+P → Reset Settings**)

## FAQ

**Q1: What is VS Code?**  
**A:** A lightweight code editor by Microsoft with features like terminal, extensions, and Git.

**Q2: Supported OS?**  
**A:** Windows, macOS, Linux

**Q3: Does it need internet?**  
**A:** Only for extensions, updates, and Git.

**Q4: What is IntelliSense?**  
**A:** Code auto-suggestion feature.

**Q5: App closing automatically?**  
**A:** Update VS Code via **Help → Check for Updates**
