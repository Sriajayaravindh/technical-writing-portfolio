## Introduction

Postman is an API platform developed by Postman, Inc. This guide helps users to successfully download, install, verify, and uninstall the app.

## Who This Guide Is For

This guide is intended for:

* Software Developers and IT Support Teams looking to install Postman on their Windows for the first time.
* Beginners with basic computer knowledge looking to install Postman on their Windows.

---

## Downloading Postman

### Step 1: Visit the official website

Go to the official website of Postman:
https://www.postman.com/downloads/

> ⚠️ **Warning:** Always download from the official website only. Avoid third-party sites.

### Step 2: Download the app

Click on **Windows x64** and wait for the download to complete.

> 💡 **Tip:** Note where the file is downloaded.

**Expected Result:** Installer file is downloaded successfully.

---

## Installation Steps

### Step 1: Find the downloaded file

Go to the **Downloads folder** in Windows.

### Step 2: Install the app

Double-click **Postman (x64)** to start installation.
Postman installs automatically.

### Step 3: Launch Postman

Postman opens automatically after installation.

**Expected Result:** Postman is installed successfully.

---

## Post-Installation Setup

### Step 1: Create a free account

1. Enter your email → click **Create Free Account**
2. Set name and password → click **Create Free Account**
3. Verify email using the code sent
4. Click **Allow access** in Windows security alert
5. Enter name and role → type a request in the request box
6. Click **Get started with AI**

> 💡 **Tip:** You can type “Send a GET request” to begin.

**Expected Result:** Account created successfully.

---

### Step 2: Create a new workspace

1. Click the **drop-down icon** (top left)
2. Click **Create**
3. Choose preferences → click **Next**
4. Enter workspace name → choose type → set access
5. Click **Create**

**Expected Result:** Workspace created successfully.

---

### Step 3: Change the Color Theme

1. Go to **Settings icon** → **App settings**
2. Select **Themes**
3. Choose theme for daytime
4. Choose theme for nighttime

> 💡 **Tip:** Dark theme is better for long usage.

**Expected Result:** Theme updated successfully.

---

## Verifying the Installation

* [ ] Postman launches without errors
* [ ] Version check: **Settings → App settings → About**
* [ ] Core features (requests, console, integrations) work

**Expected Result:** Installation verified successfully.

## Uninstallation

### Windows

1. Open **Start menu** → search **Control Panel**
2. Click **Programs → Programs and Features**
3. Search **Postman x64 12.2.2**
4. Right-click → **Uninstall**

**Expected Result:** Postman removed successfully.

## Troubleshooting

### Issue 1: Installation fails

**Cause:**

* Low storage
* System not compatible
* Corrupt installer

**Fix:**

1. Free up disk space
2. Check system requirements (**Settings → System → About**)
3. Download latest installer
4. Retry installation

> ⚠️ Do not interrupt installation

---

### Issue 2: App closes automatically

**Cause:**

* Outdated version
* Corrupt install

**Fix:**

1. Update: **Menu → Help → Check for Updates**
2. Reinstall latest version

---

### Issue 3: Unable to uninstall

**Cause:**

* App running in background
* No admin rights

**Fix:**

1. Open **Task Manager (Ctrl+Shift+Esc)** → end Postman
2. Ensure admin access
3. Restart system
4. Retry uninstall
